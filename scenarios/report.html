研报蒸馏

百页研报蒸成一页干货，每条标源页码，附核验记录。

四分身流水线 · 31/31 核验命中 · 方法论开源

包含什么

一页知识卡，固定三块结构：核心结论 / 可复用方法 / 关键数据。
每条信息标源页码，附核验记录——可回溯、可复核。
适合：投研个人复盘、企业情报简报。

怎么做（全程线上）

  1. 选题：定边界——这份研报解决什么问题
  2. 蒸馏：抽取内容，逐条带源页码
  3. 审校：独立复核，不合格打回重蒸（闭环）
  4. 归档：成卡入库，人读版 + 机器可读版
四分身流水线：选题 → 蒸馏 → 审校 → 归档。

交付与验收

一页知识卡（三块结构）+ 源页码 + 核验记录。
验收标准：卡上每条信息都能翻回研报原文页码；方法论已在 GitHub 开源，流程透明可查。
战绩依据：实战核验 31/31 全命中（方法论核验记录，非客户案例）。
