# DistillLab 蒸馏研究室 · 主页仓库

这是 [distilllab.github.io](https://distilllab.github.io) 的源码仓库——DistillLab 蒸馏研究室的官方主页（纯静态单页站点）。

## 这个组织是做什么的

DistillLab（蒸馏研究室）聚焦两件事：

1. **知识蒸馏**：把研报、书籍、长文档蒸馏成一页可复用的知识卡
2. **AI 工具开源**：把日常验证过的 AI 工作流做成开源技能，回馈社区

## 旗下的开源项目

| 仓库 | 说明 |
|------|------|
| [yanbao-distill](https://github.com/distilllab/yanbao-distill) | 研报蒸馏流水线：三遍读法 + 四分身（选题/蒸馏/审校/归档），自动产出知识卡 |
| [workbuddy-memory-kit](https://github.com/distilllab/workbuddy-memory-kit) | AI 防失忆技能包：`memory-anchor`（记忆治理）+ `cross-window-handoff`（跨窗口交接），专治 AI 换窗口就忘事 |

## 本仓库结构

- `index.html` — 主页页面（中文）
- `llms.txt` — 面向 AI 助手的站点说明
- `CNAME` — 自定义域名配置
- `panorama.svg` — 页面配图
